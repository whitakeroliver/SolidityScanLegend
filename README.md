# SolidityScanLegend

SolidityScanLegend enables real-time, high-performance data extraction and analysis through scalable, auto-scaling architecture and efficient query processing.

With SolidityScanLegend, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/SolidityScanLegend.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
